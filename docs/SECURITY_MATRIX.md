# Security Matrix

| Recurso                                        | Owner                                        | Parceiro participante                                             | Admin autorizado                                    | Anônimo                         |
| ---------------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------- | ------------------------------- |
| Perfil público                                 | Ler; editar campos permitidos                | Ler campos públicos                                               | Ler conforme função                                 | Nenhum acesso direto            |
| Perfil privado                                 | Ler/escrever próprio                         | Nenhum                                                            | Metadados mínimos e auditados                       | Nenhum                          |
| Fitness/health/acessibilidade/nutrição         | Ler/escrever próprio                         | Nenhum                                                            | Altamente restrito, propósito específico e auditado | Nenhum                          |
| Índice WillTreino ID                           | Nenhum acesso direto                         | Nenhum acesso direto                                              | Servidor somente                                    | Nenhum                          |
| Convite                                        | Ler sender/receiver; transições via Function | Igual, quando receiver/sender                                     | Suporte limitado e auditado                         | Nenhum                          |
| Group session                                  | Ler/ações próprias autorizadas               | Ler se participante; sem dados sensíveis                          | Suporte limitado                                    | Nenhum                          |
| Estado operacional do participante             | Atualizar apenas o próprio                   | Ler apenas `aguardando`/`executando`/`descansando`; nunca alterar | Limitado/auditado                                   | Nenhum                          |
| Próprios sets em grupo                         | Ler/criar eventos imutáveis próprios         | Nenhum por padrão; nunca escrever                                 | Limitado/auditado                                   | Nenhum                          |
| Sessão/histórico individual                    | Ler/escrever próprio                         | Nenhum por padrão                                                 | Limitado/auditado                                   | Nenhum                          |
| Weekly stats                                   | Ler próprio; sem escrita client              | Nenhum                                                            | Rebuild/operação por servidor                       | Nenhum                          |
| Fotos de progresso                             | Ler/escrever próprio                         | Nenhum                                                            | Exceção altamente restrita                          | Nenhum                          |
| Catálogo de exercícios                         | Ler conforme publicação                      | Igual                                                             | Gerenciar por mecanismo privilegiado                | Conforme política de publicação |
| Audit logs/roles/subscription/processed events | Nenhum acesso client                         | Nenhum                                                            | Operação específica via servidor                    | Nenhum                          |

As Rules implementam esta matriz por caminho e campo, não apenas por autenticação. O log bruto de performance em grupo é privado; um compartilhamento futuro deve expor uma projeção operacional mínima e opt-in, nunca os motivos privados de uma adaptação.
